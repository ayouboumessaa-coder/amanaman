# AMAN · أمان 🌸
> **المنصة الوطنية للوقاية من العنف ضد النساء والفتيات بالمغرب مع مساعد ذكاء اصطناعي ذكي**
> *Plateforme nationale de prévention des violences faites aux femmes au Maroc avec IA intelligente*

---

## 🌟 المميزات الرئيسية (Fonctionnalités)

1. **مساعد ذكي (IA Intelligente) متكيف ثقافياً وقانونياً :**
   - يعمل بالدارجة المغربية بجميع فروعها (الدارجة، الشمالية، الشرقية، الحسانية...)، العربية الفصحى، الفرنسية والإنجليزية.
   - إلمام شامل بالقانون المغربي: **القانون 103-13**، **مدونة الأسرة** (الطلاق للشقاق، النفقة، الحضانة)، و**مكافحة الابتزاز والجرائم الإلكترونية (الفصل 447 من القانون الجنائي)**.
   - توجيه طبي: كيفية الحصول على **شهادة طبية مع مدة العجز (ITT)** من المستشفيات العمومية وخلايا التكفل بالنساء ضحايا العنف.
   - يدعم الاتصال المباشر بـ **Google Gemini AI** عند توفر مفتاح `GEMINI_API_KEY`، ويتضمن **محرك ذكاء اصطناعي محلي ذكي فائق الدقة** يعمل حتى بدون إنترنت أو بدون مفتاح خارجي!

2. **أرقام الطوارئ والدعم المباشر :**
   - **19:** الأمن الوطني (الشرطة في المجال الحضري).
   - **177:** الدرك الملكي (في القرى والمناطق القروية).
   - **8350:** خط الاستماع الوطني المجاني للاتحاد الوطني لنساء المغرب (UNFM) على مدار 24/7.
   - **15:** الوقاية المدنية والإسعاف.

3. **أدوات الحماية والأمان الفوري :**
   - **زر SOS :** إرسال الموقع الجغرافي (GPS) لشخص ثقة عبر رسالة قصيرة أو واتساب بضغطة واحدة.
   - **صفارة الإنذار :** صوت تحذيري قوي لإخافة المعتدي ولفت انتباه المحيطين.
   - **شاشة التمويه السريع (Camouflage) :** إخفاء التطبيق فوراً وعرض شاشة وهمية (آلة حاسبة أو مذكرة) بضغطة زر لحماية خصوصية الضحية إذا دخل شخص ما.
   - **الخروج السريع (Quick Exit) :** مسح الأثر الفوري وإغلاق الجلسة.

4. **تطبيق ويب تقدمي (PWA) مستقل 100% :**
   - قابل للتثبيت على الهاتف والكمبيوتر (Android, iOS, Windows, Mac).
   - دعم العمل أوفلاين (Service Worker Cache).
   - **خالي تماماً وبنسبة 100% من أي ارتباط خارجي بـ Netlify أو خدمات طرف ثالث قد تتعطل**.

## 🚀 تشغيل التطبيق (Démarrage)

### الطريقة الأولى: عبر Node.js (الموصى بها)
```bash
# الانتقال لمجلد المشروع
cd aman_pwa

# بدء السيرفر مباشرة (لا يحتاج أي تثبيت إضافي!)
npm start
# أو:
node server.js
```
افتح المتصفح على: `http://localhost:3000`

### الطريقة الثانية: فتح مباشر في المتصفح
يمكنك أيضاً فتح ملف `index.html` مباشرة في أي متصفح، وسيعمل المساعد الذكي وجميع الأدوات أوفلاين بشكل فوري.

---

## 🔑 تفعيل Google Gemini AI (اختياري)
إذا أردت تفعيل Gemini السحابي، يمكنك ضبط المتغير في النظام أو إنشاء ملف `.env`:
```env
GEMINI_API_KEY=your_api_key_here
PORT=3000
```
*ملاحظة: حتى بدون المفتاح، يعمل المساعد الذكي بكفاءة عالية بفضل المحرك الداخلي المتخصص.*
